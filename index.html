ขั้นตอนการนำไฟล์นี้ไปเปิดใช้งานบน GitHub Pages

คุณสามารถสร้างเว็บไซต์แดชบอร์ดระบาดวิทยานี้ให้อยู่บนอินเทอร์เน็ตเพื่อแชร์ให้ทีมงาน สสจ./รพ./สคร. ดูได้ฟรี ผ่าน GitHub Pages โดยทำตามขั้นตอนง่ายๆ ดังนี้:

  1. บันทึกซอร์สโค้ดไฟล์นี้เป็นชื่อ index.html
  2. ไปที่ GitHub.com แล้วล็อกอิน เข้าไปที่ **New Repository**
  3. ตั้งชื่อ Repository เช่น covid19-dashboard และเลือกเป็น **Public**
  4. อัปโหลดไฟล์ index.html เข้าไปใน Repository ดังกล่าว
  5. ไปที่เมนู **Settings** > **Pages** ใน Repository นั้น
  6. ในหัวข้อ **Build and deployment** ให้เลือก Source เป็น **Deploy from a branch** และเลือก Branch เป็น main (หรือ root) แล้วกด **Save**
  7. รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น https://username.github.io/covid19-dashboard/ สามารถเปิดดูและแชร์ได้ทันที!
